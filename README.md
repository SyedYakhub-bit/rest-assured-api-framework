# REST Assured API Framework

API test automation framework built while learning 
Rest Assured through Rahul Shetty's course.

## Tech stack
- Java
- Rest Assured
- TestNG
- Maven

## Structure
src/test/java — all test classes
src/main/java — helper/utility classes
data/ — properties and test data files

## How to run
mvn clean test

## Status
Learning project — being upgraded to production-grade framework
